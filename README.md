**End-to-End Mahine Learning for Student Placement and Salary Prediction**

Developed an end-to-end machine learning solution to predict students' employment outcomes and estimated salary based on academic performance, technical skills, lifestyle factors, and other supporting attributes. The project involved analyzing a dataset of 5,000 student records through exploratory data analysis (EDA), data preprocessing, feature engineering, and comparative modeling to identify the most effective approaches for both classification and regression tasks. The complete machine learning workflow was designed to produce reliable predictions while ensuring robust model evaluation and reproducibility.

Beyond model development, the project incorporated an automated **Scikit-Learn Pipeline** to streamline data preprocessing and model training while preventing data leakage. **MLflow** was used to track experiments, log model performance, and manage trained models for reproducibility. The final solution was deployed through both a **monolithic Streamlit application** and a **decoupled architecture** consisting of a **FastAPI backend** and a **Streamlit frontend**, demonstrating the complete lifecycle of a production-ready machine learning system. This project strengthened my practical experience in **machine learning, feature engineering, experiment tracking, model deployment, API development, and building end-to-end AI applications**.
